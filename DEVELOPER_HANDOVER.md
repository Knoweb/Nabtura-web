# NABTURA Developer Handover

## Privacy & Consent Implementation

**What the developer must NOT do:**
The developer should not simply install tracking tools and then copy their names into the Cookie Policy.

The sequence should be:
01. Confirm technology stack
→ 02. Identify cookies/storage technologies
→ 03. Classify them
→ 04. Configure consent behavior
→ 05. Update Cookie Policy
→ 06. Test consent
→ 07. Launch

In particular, optional analytics/marketing technology should be configured around the final applicable consent requirements rather than merely displaying a banner while trackers fire automatically.
